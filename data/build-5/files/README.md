# StageShift openly licensed component data — version 0.1.0, Build 5

This download is a deliberate subset of StageShift Build5. It contains twenty room-response WAVs, nine corresponding openly licensed or public-domain-source image adaptations, and the exact OPRA headphone catalogue/runtime data with attribution, licence texts and processing provenance. No account, fee or app installation is needed.

The individual content licences remain effective. This download imposes no additional testing-only, noncommercial, confidentiality or no-redistribution condition on CC-licensed content. Required attribution and applicable ShareAlike conditions must be followed. Public Domain Mark1.0 is retained as that marking, not CC0. Source creators do not endorse StageShift.

## Components

- generic/: nine OpenAIR-derived stereo WAVs, exact source/creator/licence notices, source hashes and native processing recipes. The general-room and Direct images are intentionally omitted. Direct has no foreign room audio.
- room_sets/: eleven retained room responses with exact audio/processing hashes and source/creator/change notices; nine image adaptations. Maeshowe's image uses CC BY-SA2.0, R1's image uses CC BY-SA4.0 and Usina's image uses CC BY2.0. York Minster retains its recorded PD-self/fallback marking; the others retain their recorded CC BY4.0 attribution. The independently generated Elveden and Sir Jack Lyons images are omitted. The catalogue and original app notice are reference records; image omissions are explicit in manifest.json.
- opra/: the exact Build5 normalized catalogue (with per-record source/creator attribution), runtime index/profile pack, full notices and CC BY-SA4.0. source.json identifies the pinned original snapshot and adaptation hashes.
- licenses/: complete applicable CC BY4.0, CC BY2.0, CC BY-SA2.0 and CC BY-SA4.0 texts. project/: existing app source-licence/notice reference only, without extending Apache terms to third-party content or granting new rights to omitted project-created assets.
- manifest.json and SHA256SUMS: exact downloadable file inventory and byte checksums.

No app executable, original photo inputs, project-generated images without an identified own open grant, unresolved room assets, credentials, user recordings or personal test data are included. This separate copy does not itself establish how Apple's processed app protects the licensed components.
